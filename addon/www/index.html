OEPL Multihub

Quiet hours: tags sleep through them and update afterwards. Set both to the same hour to turn them off.

The hub list is set in the addon's Configuration tab in Home Assistant.

Backup

Download the tag database: names, settings and last known state of every tag.

Restore

Load a backup from this addon or a tagDB.json from a stock access point (its Backup DB button). Tags in the file are added or get their name and settings back; other tags stay.

Import from a stock access point

Copies the tag list, names, settings and current images from a running OpenEPaperLink access point. The access point is not changed.

Variables

Values for {name} placeholders in JSON templates, set with /set_var or /set_vars. Tags that use a variable are redrawn when it changes.
